# Render Deployment Guide: ProgressPath Full-Stack LMS

This application is 100% deployment-ready for **Render (Web Service)**.

---

## 🚀 Quick Setup on Render

### Option 1: Blueprint Deployment (Fastest)
1. Push your repository to **GitHub** or **GitLab**.
2. Go to your [Render Dashboard](https://dashboard.render.com).
3. Click **New +** &rarr; **Blueprint**.
4. Connect this repository. Render will automatically read `render.yaml` and configure:
   - **Service Name**: `progresspath-platform`
   - **Environment**: Node.js (v20+)
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Health Check Path**: `/api/health`

---

### Option 2: Manual Web Service Deployment
1. Go to [Render Dashboard](https://dashboard.render.com) &rarr; **New +** &rarr; **Web Service**.
2. Connect your Git repository.
3. Configure the following fields:
   - **Name**: `progresspath` (or your preferred name)
   - **Language**: `Node`
   - **Branch**: `main`
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Health Check Path**: `/api/health`

---

## 🔑 Environment Variables to Configure in Render

In your Render Service settings &rarr; **Environment**:

| Variable | Required | Description | Example |
| :--- | :--- | :--- | :--- |
| `NODE_ENV` | **Yes** | Runtime mode | `production` |
| `PORT` | **Auto** | Port assigned by Render | *Render sets this automatically (e.g. 10000)* |
| `MONGODB_URI` | Optional | MongoDB Atlas connection string | `mongodb+srv://user:pass@cluster.mongodb.net/LMS?retryWrites=true&w=majority` *(If omitted, app automatically uses resilient zero-crash fallback store)* |
| `JWT_SECRET` | **Yes** | Secret string for JWT session auth | Any secure random 32+ character string (or auto-generated by Blueprint) |
| `ADMIN_EMAIL` | Optional | Initial super admin email | `admin@lms.local` or your personal email |
| `ADMIN_NAME` | Optional | Initial super admin display name | `Super Administrator` |
| `ADMIN_PASSWORD` | Optional | Initial super admin password | `Admin@Secure2026!` |
| `CORS_ORIGIN` | Optional | Custom production domain | `https://your-service.onrender.com` |

## 🛡️ Built-in Production Safeguards
- **Zero-Crash Database Resilience**: If MongoDB Atlas is unavailable or credentials fail, the server automatically boots on its resilient high-performance store so users never see 500 errors.
- **Render Health Checks**: `/health`, `/healthz`, and `/api/health` endpoints respond with HTTP 200 OK immediately for zero-downtime rolling deploys.
- **SPA Fallback**: Production server automatically bundles static assets and routes unknown client paths to `index.html`.
- **Security Hardening**: Anti-DDoS rate limiting, Anti-Brute force login protection, NoSQL injection sanitization, CSP and security headers pre-configured.
